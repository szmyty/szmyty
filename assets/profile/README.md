## Optimization

All SVG files must pass an SVGO pass before commit:

```sh
svgo --multipass assets/profile/banner-light.svg
svgo --multipass assets/profile/banner-dark.svg
svgo --multipass assets/profile/mark.svg
svgo --multipass assets/profile/divider.svg
```

The optimization must not remove `<title>`, `viewBox`, or accessibility
attributes. Use `--config` to disable the `removeTitle` plugin if needed.

## Regeneration Protocol

1. Read `ASSET-BRIEF.md` for the generation prompt and constraints.
2. Generate the asset in ChatGPT (or Inkscape for hand-authored edits).
3. Download the SVG or export from the vector tool.
4. Run SVGO optimization.
5. Run the asset validator: `python profile/validate_assets.py assets/profile/`
6. Replace the file in this directory.
7. Verify `README.md` `<picture>` references still resolve.
8. Commit with a descriptive message referencing the asset name.
