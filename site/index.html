Ego Hygiene Architecture

The Ego Hygiene platform is a privacy-first, offline-capable personal data ecosystem. The diagram below shows the principal layers. Each layer is also described in the list that follows.

Architecture layer descriptions
  1. UI Layer — React Native (mobile) and Tauri (desktop) front-ends sharing a common component library.
  2. API Gateway — Local REST or IPC bridge; no external calls in default configuration.
  3. Core Services — Rust for performance-critical paths; Python for data processing and ML inference.
  4. Local Storage — SQLite for structured data; file system for media and artefacts. No cloud sync by default.
