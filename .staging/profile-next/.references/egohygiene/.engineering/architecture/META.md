# META

> *The universal conceptual building blocks used to model complex systems.*

---

# Overview

META defines the common language used throughout the Ego Hygiene ecosystem for representing systems.

It exists above any individual application, ontology, or implementation.

Rather than describing a specific domain, META defines the universal concepts from which domain-specific models are constructed.

Every application in the ecosystem builds upon these concepts.

---

# Purpose

META provides a shared conceptual vocabulary that allows different projects to remain architecturally consistent while modeling entirely different domains.

Examples include:

- Ego Hygiene models personal development.
- Mindgarden models knowledge.
- Dreamscape models creative production.

Although each application has a different ontology, they share the same conceptual building blocks.

---

# Universal Concepts

## Entity

Something that exists within a system.

Examples:

- Reflection
- Goal
- Memory
- Concept
- Character

---

## Relationship

A meaningful connection between entities.

Relationships describe how information is connected rather than existing in isolation.

---

## State

The current condition of an entity or system.

State changes over time.

---

## Event

Something that occurs.

Events often create or modify state.

---

## Signal

An observable piece of information.

Signals contribute evidence but rarely provide complete understanding on their own.

---

## Context

Relevant information surrounding an entity, event, or decision.

Context provides meaning.

---

## Memory

Information intentionally preserved across time.

Memory enables continuity and learning.

---

## Artifact

A generated or persistent representation of information.

Examples include:

- documents
- summaries
- infographics
- reports
- visualizations

---

## Engine

A system responsible for transforming information.

Examples include:

- Insight Engine
- Context Engine
- Memory Engine
- Artifact Generation Engine

---

## Registry

A mechanism for discovering capabilities dynamically.

Registries support modularity and extensibility.

---

## Lifecycle

The progression of an entity or system through time.

Examples include:

- application startup
- authentication
- synchronization
- user journeys

---

## Workflow

A repeatable sequence of transformations that produces a desired outcome.

---

# Relationships Between Concepts

Complex systems emerge from interactions between these concepts.

```text
Signals

↓

Context

↓

Engines

↓

Artifacts

↓

Understanding
```

Each application specializes these concepts through its own ontology.

---

# Relationship to Ontology

META defines *how* systems are modeled.

An ontology defines *what* exists within a specific system.

META remains stable across projects.

Ontologies evolve according to the needs of individual applications.

---

# Summary

META establishes the universal conceptual language used throughout the Ego Hygiene ecosystem.

It provides a shared foundation for modeling systems while allowing each application to define its own unique ontology, architecture, and user experience.
