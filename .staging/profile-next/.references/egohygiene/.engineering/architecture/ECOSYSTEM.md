# Ecosystem

> *A map of the Ego Hygiene ecosystem and how its components relate to one another.*

---

# Overview

The Ego Hygiene ecosystem is composed of multiple interconnected systems that work together to support human understanding, personal growth, creativity, and knowledge.

Each project has a distinct purpose.

Together they form a cohesive platform rather than a collection of independent applications.

The ecosystem is designed around shared engineering principles, reusable foundations, and evolving knowledge.

---

# Architecture

The ecosystem is organized into several layers.

```text
Vision

↓

Engineering Methodology

↓

Flutter Foundation

↓

Applications

↓

Publishing

↓

Website

↓

Research
```

Each layer builds upon the one above it.

---

# Engineering Methodology

The engineering methodology defines how systems are designed, specified, implemented, validated, and evolved.

It provides the common language used across every project.

Examples include:

- specifications
- ontology
- methodology
- AI workflows
- GitHub Issues
- architecture reviews

---

# Flutter Foundation

The Flutter Foundation provides reusable infrastructure shared across future applications.

Examples include:

- startup lifecycle
- authentication
- routing
- storage
- localization
- AI abstractions
- design system
- plugin architecture

Applications inherit capabilities from the foundation rather than rebuilding them.

---

# Applications

Applications solve specific domain problems while sharing common infrastructure.

Current and future applications include:

- Ego Hygiene
- Mindgarden
- Dreamscape

Each application defines its own ontology while sharing the same engineering foundation.

---

# Publishing

The publishing platform transforms knowledge into reusable educational artifacts.

Examples include:

- articles
- magazine
- research summaries
- infographics
- visual explanations

Publishing communicates ideas developed throughout the ecosystem.

---

# Website

The website serves as the public interface to the ecosystem.

Its responsibilities include:

- documentation
- downloads
- articles
- research
- roadmap
- community
- project discovery

The website explains the ecosystem rather than replacing the applications.

---

# Research

Research grounds the ecosystem in continuous learning.

Sources may include:

- scientific literature
- technical research
- philosophy
- psychology
- contemplative traditions
- experimentation
- lived experience

Research informs the evolution of both the applications and the engineering methodology.

---

# Artificial Intelligence

Artificial intelligence is not a standalone product.

It is a capability shared across the ecosystem.

AI exists to:

- organize knowledge
- synthesize information
- support reflection
- generate artifacts
- assist creativity

AI augments human understanding rather than replacing it.

---

# Shared Philosophy

Every project within the ecosystem shares several core ideas:

- human-centered design
- intellectual humility
- local-first thinking
- modular architecture
- reusable systems
- continuous learning
- evidence-informed reasoning
- respect for individual experience

These principles create consistency while allowing each application to evolve independently.

---

# Evolution

The ecosystem is intentionally designed to grow.

New applications, packages, publishing formats, research initiatives, and AI capabilities should integrate naturally into the existing architecture rather than requiring fundamental redesign.

The architecture should evolve through extension rather than replacement.

---

# Summary

The Ego Hygiene ecosystem is a collection of interoperable systems built upon a shared engineering methodology and philosophical foundation.

Each component has a distinct responsibility.

Together they support a common mission:

To help people better understand themselves, each other, and the systems they inhabit through thoughtful engineering, continuous learning, and human-centered design.
