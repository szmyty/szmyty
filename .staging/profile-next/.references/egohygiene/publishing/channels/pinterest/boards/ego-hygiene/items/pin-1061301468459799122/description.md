# A reflective infographic exploring the difference between relationships built on emotional intensity and relationships built on safety, trust, and mutual growth. This piece examines trauma bonding, nervous system activation, secure attachment, and the ways chaos can sometimes be mistaken for connection. A reminder that healthy love is not defined by how intensely it hurts, but by how consistently it supports your well-being. #trauma-bond #healthy-relationships #attachment-healing #nervous-system #emotional-awareness
