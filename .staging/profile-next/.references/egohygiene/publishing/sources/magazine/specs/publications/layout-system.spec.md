Purpose

This specification defines the structural layout language used throughout Ego Hygiene publications.

The Layout System is responsible for:

composition
hierarchy
spacing
content flow
structural organization

The Layout System is independent from:

atmosphere
visual styling
textures
lighting
content

The Layout System answers:

«Where does information live?»

---

Core Philosophy

Layout exists to organize understanding.

The purpose of layout is not decoration.

The purpose of layout is:

clarity
navigation
pacing
emphasis
comprehension

A strong layout allows a reader to understand the structure of a page before reading the content.

---

Relationship To Other Systems

The publication stack is:

Visual DNA
→
Environment
→
Layout
→
Components
→
Content

Layout acts as the bridge between atmosphere and content.

---

Layout Responsibilities

The Layout System owns:

page hierarchy
regions
spacing
alignment
grouping
reading flow

The Layout System does NOT own:

textures
lighting
particles
color grading
typography styling

Those belong elsewhere.

---

Hierarchy Philosophy

Every page should establish:

primary focus
secondary focus
supporting information

Readers should immediately understand:

where to look first
where to look second
where to look last

Hierarchy should feel natural.

Never confusing.

---

Layout Regions

A page may contain one or more regions.

Regions are reusable structural zones.

---

Header Region

Purpose:

establish context

Common contents:

title
subtitle
introduction
issue metadata

Typical priority:

highest

---

Illustration Region

Purpose:

visual storytelling
symbolism
emotional engagement

Common contents:

hero artwork
diagrams
visual metaphors

Typical priority:

high

---

Content Region

Purpose:

communicate information

Common contents:

body text
educational content
explanations

medium

---

actionable guidance

exercises
actions
techniques
recommendations

Typical priority:

medium

benefits

transformations

prompts

medium

Purpose:

highlight important information

Common contents:

quotes

supporting

provide completion

summaries

final

---

Layout Density

Pages should feel:

rich
substantial
meaningful

But should remain:

readable
breathable
organized

Avoid:

empty minimalism
overwhelming clutter

Target:

«dense meaning with clear structure.»

---

Reading Flow

Readers should naturally move through a page.

Typical flow:

title
→
illustration
→
supporting content
→
practices
→
outcomes
→
closing

Flow should feel intentional.

Not accidental.

---

Reusability

Layouts should be reusable.

A layout is not tied to:

a specific topic
a specific pillar
a specific illustration

A layout defines:

structure

not content.

---

Layout Extraction Process

Reference Page
→
Structural Analysis
→
Region Identification
→
Layout Pattern
→
Layout System

Layout patterns should emerge from references.

Not speculation.

---

Validation

When reviewing a page ask:

Is the structure clear?

before asking:

Is it visually impressive?

Clarity comes first.

---

Long-Term Goal

The publication should eventually rely on a small number of reusable layouts.

Example:

5–15 layouts

supporting:

hundreds of pages

This creates consistency while reducing design complexity.

---

Guiding Principle

Layout organizes understanding.

A reader should understand the structure of a page before they understand the content.
