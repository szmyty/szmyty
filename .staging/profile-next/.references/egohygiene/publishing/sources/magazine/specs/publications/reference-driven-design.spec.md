Purpose

This specification defines how visual references are used throughout Ego Hygiene publication systems.

The goal is not to invent designs.

The goal is to extract systems from proven designs.

References act as the canonical source of truth.

---

Core Philosophy

References are truth.

The role of the designer is not:

invention

The role of the designer is:

observation
extraction
decomposition
systematization

The workflow is:

reference
→
analysis
→
system extraction
→
reusable assets
→
publication generation

---

Design Principle

Do not ask:

What should this look like?

Ask:

What does the reference already tell us?

The publication should emerge from the reference material.

Not from arbitrary stylistic decisions.

---

Reference Hierarchy

Not all references are equal.

---

Canonical References

Canonical references define the visual language of the publication.

Examples:

cover pages
finalized pillar pages
approved spreads
finished publication assets

Canonical references are treated as:

«source material for visual DNA extraction.»

---

Supporting References

Supporting references help clarify details.

Examples:

textures
typography examples
lighting examples
illustration references

Supporting references help refine systems but do not override canonical references.

---

Exploratory References

Exploratory references provide inspiration.

Examples:

Pinterest
magazines
comic books
posters
packaging

These may influence future designs but should never override publication identity.

---

Extraction Process

Every reference should be analyzed through multiple lenses.

---

Visual DNA Extraction

Identify:

color language
typography
material language
symbolism
atmosphere
emotional tone

Output:

visual-dna.spec.md

---

Environment Extraction

Identify:

lighting
particles
textures
atmospheric effects
environmental storytelling

Output:

environment-system.spec.md

---

Layout Extraction

Identify:

hierarchy
spacing
composition
content flow
section ordering

Output:

layout-system.spec.md

---

Component Extraction

Identify:

reusable structures
recurring elements
repeated patterns

Examples:

cards
headers
frames
callouts
effect panels

Output:

component-system.spec.md

---

Archetype Extraction

Identify:

recurring page types
reusable page structures
publication patterns

Examples:

pillar page
infographic page
reflection page
article page

Output:

page-archetypes.spec.md

---

Design Decomposition

A completed page should never be treated as a single object.

Instead decompose it into:

visual dna
environment
layout
components
content

Example:

Movement Page

becomes:

Visual DNA
+
Environment
+
Pillar Archetype
+
Practice Cards
+
Effect Panel
+
Content

This decomposition enables reuse.

---

Reuse Philosophy

The objective is not:

recreate pages

The objective is:

recreate systems

Systems should be reusable.

Pages are instances of systems.

---

Fidelity Philosophy

When extracting from references:

Prioritize:

visual fidelity
emotional fidelity
structural fidelity

Avoid:

accidental redesign
unnecessary modernization
aesthetic drift

The goal is not:

inspired by

The goal is:

derived from

---

Design Evolution

References may evolve over time.

When stronger references appear:

audit
compare
extract
reconcile

The publication system should evolve through improved references rather than arbitrary redesign.

---

AI-Assisted Extraction

AI systems should be used to:

identify patterns
compare references
extract systems
organize observations
generate specifications

AI should not:

invent replacement designs
override canonical references
introduce unrelated aesthetics

---

Validation

When evaluating a generated asset ask:

Does it match the reference?

before asking:

Do I personally prefer it?

Reference fidelity takes priority over subjective preference.

---

Long-Term Goal

The long-term objective is:

reference
→
specification
→
environment
→
components
→
templates
→
pages

This creates a scalable publication architecture capable of generating:

magazines
books
comics
guides
visual synapses
future publication formats

while preserving a coherent visual identity.

---

Guiding Principle

Do not recreate artifacts.

Extract systems from artifacts.

The reference is not inspiration.

The reference is evidence.
