# Ego Hygiene  
## Edition 1 — Orientation

**Ego Hygiene** is a system for maintaining balance across the human experience.  
This magazine is not instructional, prescriptive, or aspirational.  
It exists to **externalize the map** — so it doesn’t have to live entirely in your head.

Edition 1 focuses on **orientation**:  
understanding the core regulatory forces that keep a person stable, grounded, and human.

---

## What This Edition Is

- A **visual field guide** for self-regulation
- A **non-linear system** (pages can be entered in any order)
- A **container for balance**, not a checklist for self-improvement
- A calm reference you can return to when internal clarity is unavailable

This is not therapy.  
This is not a belief system.  
This is not something to “complete.”

---

## Core Idea

Every practice in this magazine exists to balance another.

No single practice is “the answer.”  
Overuse of any one creates imbalance.  
Health emerges from **movement between opposites over time**.

The system is intentionally symmetrical.

---

## The Regulation Axes

Edition 1 is structured around **five core axes**, each representing a dimension of human regulation.

### 🕰️ Time / Orientation  
**Presence** ↔ **Goals**  
- Now ↔ Next  
- Anchoring attention ↔ Directing attention

### ⚡ Energy / Arousal  
**Movement** ↔ **Rest**  
- Discharge ↔ Integration  
- Activation ↔ Recovery

### 🧠 Ego / Agency  
**Affirmations** ↔ **Prayer**  
- Self-definition ↔ Surrender  
- Agency ↔ Release of control

### ❤️ Emotion / Integration  
**Gratitude** ↔ **Acceptance**  
- Appreciation ↔ Permission  
- Integrating the good ↔ Allowing the hard

### 🫂 Social / Relational  
**Community** ↔ **Solitude**  
- Co-regulation ↔ Self-contact  
- Shared presence ↔ Inward clarity

These axes form a **closed system**.  
Nothing essential is missing.

## Design Principles

- **Non-prescriptive** — nothing here is mandatory  
- **Non-hierarchical** — no practice outranks another  
- **Nervous-system aware** — regulation over optimization  
- **Artifact-first** — visual containers before abstraction  

The magazine is meant to **hold insight**, not demand action.
