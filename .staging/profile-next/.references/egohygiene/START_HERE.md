## What is this?

Ego Hygiene is a local-first, privacy-respecting Flutter application for structured reflection, memory, and personal growth.

It is also a reference implementation of a reusable Flutter engineering foundation designed to support future applications.

## Core Principles

- **Architecture first** — understand the system before modifying it
- **Foundation before feature** — shared infrastructure precedes application-specific work
- **Externalized cognition** — decisions, patterns, and rationale live in the repository
- **Human-AI collaboration** — humans define, AI implements
- **Reflection over reaction** — deliberate choices over reactive ones
